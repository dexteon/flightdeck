# Hermes status transition matrix

Generated by `scripts/spike_matrix.py` against the `flightdeck-test` board.
Rows are the current status, columns the requested one, via
`PATCH /api/plugins/kanban/tasks/{id}?board=<slug>` with `{"status": <column>}`.

`ok` means Hermes accepted it *and* a follow-up read confirmed the new status.

## Refusal messages

- `400 Cannot set status to 'running' directly; use the dispatcher/claim path`  (e.g. triage -> running)
- `409 status transition to 'blocked' not valid from current state`  (e.g. triage -> blocked)
- `409 status transition to 'done' not valid from current state`  (e.g. triage -> done)
- `409 status transition to 'review' not valid from current state`  (e.g. triage -> review)
- `409 status transition to 'scheduled' not valid from current state`  (e.g. triage -> scheduled)
